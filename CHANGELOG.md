# Changelog

All notable changes to the `lakmus` package are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project follows
[semantic versioning](https://semver.org/spec/v2.0.0.html).

The suite format and the `run.json` schema have their own version numbers, declared in
`docs/spec/suite-format.md` and in each run file. Changes to either are called out here under
**Changed** with the version they move to.

## [Unreleased]

### Added

- Suite format specification, draft version 0.1 (`docs/spec/suite-format.md`).
- Architecture documentation and the first four decision records, including the repository
  boundaries for the organisation ([ADR 0004](docs/adr/0004-repository-boundaries.md)).
- Package skeleton and `lakmus --version`. No suite can be run yet.
- Repository baseline: licence, contribution, conduct and security policies, issue and pull request
  templates, dependency updates, and continuous integration on Python 3.11 to 3.13.
